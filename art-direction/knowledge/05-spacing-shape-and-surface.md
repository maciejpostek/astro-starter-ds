# Spacing, Shape, And Surface

Status: universal knowledge.

Spacing, geometry, borders, and surfaces form a material language. Consistent
token use is necessary but does not by itself create a coherent visual
character.

## Spacing

Define:

- base spacing relationships;
- density profiles;
- internal component padding;
- group spacing;
- section rhythm;
- text-to-control relationships;
- media-to-content relationships;
- exceptions based on optical balance.

Spacing should express grouping and hierarchy. Do not select the next token in
a scale without identifying the relationship it represents.

## Negative Space

Specify where the project deliberately creates:

- isolation;
- breathing room;
- pacing;
- asymmetrical counterweight;
- unused grid tracks;
- edge tension.

Negative space should be reviewed at page scale, not only inside components.

## Shape

Define:

- radius family;
- sharp versus soft character;
- circular exceptions;
- recurring cuts, corners, notches, or markers;
- image-mask behavior;
- icon geometry relationships.

A distinctive signature such as a corner marker should have a semantic or
systemic placement rule. Repeating decoration without a rule creates visual
clutter rather than unity.

## Borders

Specify:

- when borders separate content;
- default and emphasized weights;
- full, partial, or one-sided treatment;
- interaction-state behavior;
- relationship to shadows and surfaces.

## Surface And Elevation

Define whether separation is expressed primarily through:

- whitespace;
- border;
- background shift;
- shadow;
- overlap;
- scale;
- motion.

Do not apply every mechanism simultaneously. The material language should
prioritize a small number of consistent cues.

## Optical Correction

Allow documented optical correction for:

- icon centering;
- text and icon balance;
- border compensation;
- asymmetric shapes;
- baseline alignment;
- perceived rather than mathematical spacing.

Optical exceptions must remain local to the component contract and must not
create an undocumented parallel token system.
