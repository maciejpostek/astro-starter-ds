# Swiss International Style

Status: universal reference, not a starter default.

This file records practical principles associated with Swiss International
Style. A project may adopt, reinterpret, or reject them. The label alone must
never activate these rules.

## Common Principles

- grid-led composition;
- objective information hierarchy;
- asymmetrical but balanced layouts;
- strong alignment;
- disciplined typography;
- purposeful negative space;
- restrained ornament;
- clarity through proportion, rhythm, and contrast;
- photography or graphic form integrated with the grid;
- repeated systems that allow controlled variation.

## Operational Translation

Possible project rules include:

- use a declared column and baseline grid;
- align major text roles to shared starts;
- create hierarchy through scale, weight, spacing, and position;
- use asymmetry while preserving visual balance;
- limit decorative effects that do not clarify content;
- use negative space as an active counterweight;
- allow typography to carry brand expression;
- define repeatable span and offset families.

These are options, not defaults. The Brand Expression Contract must state which
ones are adopted.

## Avoid Literal Styling

Do not reduce Swiss International Style to:

- Helvetica by default;
- red, black, and white;
- every heading aligned left;
- visible grid lines;
- poster imitation;
- minimalism without hierarchy;
- random asymmetry.

The useful principle is systematic visual organization, not historical surface
copying.

## Evidence Requirements

When a project cites this direction, provide:

- approved references;
- annotated grid and alignment traits;
- typography decisions;
- examples of intended asymmetry;
- examples of excessive rigidity to avoid;
- component and responsive interpretations.

## Digital-System Test

A Swiss-influenced digital system is successful when:

- components share clear alignment and hierarchy;
- responsive layouts retain the organizing logic;
- controls remain accessible and semantically correct;
- repetition creates unity without eliminating useful contrast;
- new pages can be generated from rules rather than copied compositions.
