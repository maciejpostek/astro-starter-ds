# Composition And Grid

Status: universal knowledge.

Composition controls relationships across a component, section, page, and
sequence of pages. A grid is a decision framework for those relationships, not
only a visible column overlay.

## Grid Roles

Define roles before assigning tracks:

- primary content track;
- supporting context track;
- media track;
- navigation or utility track;
- deliberate empty track;
- breakout or emphasis track.

The same numerical grid can create very different designs depending on which
roles are assigned to its areas.

## Composition Grammar

A project contract should specify:

- container behavior;
- column and baseline logic;
- dominant alignments;
- allowed span families;
- common text-to-media ratios;
- symmetry or asymmetry preference;
- density range;
- vertical section rhythm;
- edge and breakout behavior;
- rules for deliberate empty space.

## Baseline And Vertical Rhythm

Baseline logic creates continuity across type, controls, and sections.

Specify:

- body-text rhythm;
- heading-to-body relationships;
- component control heights;
- label and metadata offsets;
- section spacing sequences;
- exceptions for optical alignment.

Do not force every object onto one baseline if its role requires a different
rhythm. Document the relationship between rhythms instead.

## Balance Across A Grid

To assess balance:

1. identify visually heavy elements;
2. inspect their distance from edges and other heavy elements;
3. compare occupied and empty areas;
4. check whether emphasis matches content priority;
5. test long and short content;
6. inspect desktop, intermediate, and mobile compositions.

Balance may be:

- symmetrical;
- asymmetrical but anchored;
- radial;
- modular;
- sequential.

The chosen model must be named in the project contract.

## Modular Composition

Modularity becomes operational when the project defines:

- the base unit or family of units;
- repeated module dimensions;
- alignment and attachment rules;
- valid combinations;
- controlled offsets;
- how modules collapse or reorder;
- which elements may break the module.

Do not interpret modularity as a requirement to place every object inside a
box. Modules may be expressed through alignment, spacing, repetition, type,
cropping, or content structure.

## Responsive Transformation

Responsive behavior is not only proportional shrinking.

Specify which relationships:

- remain invariant;
- stack;
- reorder;
- simplify;
- change emphasis;
- become horizontally scrollable;
- collapse into disclosure;
- lose decorative elements.

The mobile composition must preserve the creative thesis and hierarchy, not
only fit the viewport.

## Composition Evidence

Useful evidence includes:

- annotated Figma frames;
- grid overlays;
- desktop and mobile pairs;
- examples with long and short content;
- diagrams showing alignment lines;
- rejected alternatives with reasons.
