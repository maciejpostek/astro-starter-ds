# Astro Design System Agent Instructions

Before UI, design-system, component, layout, style, token or documentation
changes, read `AGENTIC-RULES.json`.

Before brand, content, information-architecture or page-composition work, also
read `project-context/README.md` and the relevant populated context folders.
Treat missing project context as an explicit input gap; do not infer a brand,
audience, offer or business model from the starter examples.

Before brand-sensitive visual design, art-direction exploration, component
polish, reference-driven work or visual redesign, also read
`art-direction/README.md`, `.agentic-rules/08-brand-expression.md` and the
project contract under
`project-context/brand-foundations/brand-expression/`. A contract that is not
`approved` cannot be used as production visual direction.

For Figma MCP design generation, Astro implementation or reconciliation tasks,
also read `Figma2Astro Agentic Rules/README.md` and the relevant numbered
mapping rule. This includes documentation layouts created directly in Figma.
For layout work, the required mapping is
`Figma2Astro Agentic Rules/04-layout.md`.
For typography work, the required mapping is
`Figma2Astro Agentic Rules/05-typography.md`.
For Figma component-library work, also read
`Figma2Astro Agentic Rules/07-component-library-roadmap.md` and the numbered
adapter for the component family. Actions use
`Figma2Astro Agentic Rules/06-actions-components.md`.
Forms use `Figma2Astro Agentic Rules/08-forms-components.md`.
Data Display uses
`Figma2Astro Agentic Rules/09-data-display-components.md`.
Text uses `Figma2Astro Agentic Rules/10-text-components.md`.
Content uses `Figma2Astro Agentic Rules/11-content-components.md`.
Disclosure uses
`Figma2Astro Agentic Rules/12-disclosure-components.md`.
Media uses `Figma2Astro Agentic Rules/13-media-components.md`.
Visual uses `Figma2Astro Agentic Rules/14-visual-components.md`.
Navigation uses `Figma2Astro Agentic Rules/15-navigation-components.md`.
Cards use `Figma2Astro Agentic Rules/16-cards-components.md`.
Sidepanels use `Figma2Astro Agentic Rules/17-sidepanels-components.md`.
Timeline uses `Figma2Astro Agentic Rules/18-timeline-components.md`.

For structural or reusable-system changes, also read:

- `AGENTIC-RULES.md`
- `DESIGN-SYSTEM-FRAMEWORK.md`
- the relevant `.agentic-rules/*.md` category file

Use the smallest relevant rule set for the task. Do not read every category file
for micro-changes unless the task is global or architectural.

Do not introduce client, portfolio or organization-specific names into the
starter foundation. Project-specific content belongs in `project-context`,
project routes, project data and project assets.
